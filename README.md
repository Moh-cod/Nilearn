# Nilearn

A lightweight digital library for Sudanese Grade 12 students.

# About

Nilearn provides students with a simple way to find and access
educational resources such as books, notes, and past papers.

It was designed with limited bandwidth and unreliable internet
access in mind.

## Features

- Browse educational resources
- Search resources
- Filter by subject
- View resource details
- Download PDFs
- Admin upload system
- Arabic student-facing interface

## Built With

- Python
- Flask
- SQLite
- HTML
- CSS

## Live Demo

https://nilearn.onrender.com

## Status

Nilearn is currently an MVP being tested with a small group of students.
